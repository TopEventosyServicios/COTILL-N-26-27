# Cotillón 2027

Web estática promocional preparada para GitHub Pages.

## Estructura
- `index.html` — experiencia interactiva
- `videos/` — vídeos sin audio, optimizados para web
- `audio/voz.mp3` — voz en off
- `audio/musica.mp3` — música de fondo
- `fotos/` — imágenes del collage

## Publicar en GitHub Pages
Sube todo el contenido de esta carpeta a la raíz del repositorio. Después ve a Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)` > Save.
